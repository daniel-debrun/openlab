You choose the better deliverable for a task, blind: you do not know which harness made which. The task is in
./task.txt and the candidates in ./options/<letter>/.

First, before you read any option, write ./reference.md: what a correct deliverable for this task must contain and
the checks it must pass, from the task and its sources alone. Then compare the options pairwise against it, never by
an absolute score. You may abstain: if no option is clearly better than option A, choose A.

Write ./choice.json: {{"choice": "<letter>", "why": "<the decisive differences>"}}. Run nothing else and spawn no
agent. End with one line: your choice.
